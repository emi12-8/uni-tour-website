Datenschutz

Campus-Kompass ist ein studentisches Lehrprojekt an der Ernst-Abbe-Hochschule Jena, entstanden mit Unterstützung von Prof. Stepping und Prof. Erfurth. Auf dieser Seite erklären wir, welche Daten beim Besuch dieser Website verarbeitet werden. Ergänzend gilt die Datenschutzerklärung der Ernst-Abbe-Hochschule Jena.

1. Verantwortliche Stelle

Ernst-Abbe-Hochschule Jena
Carl-Zeiss-Promenade 2, 07745 Jena
E-Mail: praesidium@eah-jena.de

Datenschutzbeauftragte(r) der Hochschule:
E-Mail: datenschutz@eah-jena.de

2. Hosting über GitHub Pages

Diese Website liegt auf GitHub Pages, einem Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Beim Aufruf der Seiten verarbeitet GitHub technisch notwendige Daten, insbesondere Ihre IP-Adresse, Datum und Uhrzeit des Abrufs sowie Angaben zu Browser und Betriebssystem. Das ist nötig, um die Website auszuliefern und vor Missbrauch zu schützen. Dabei können Daten in die USA übermittelt werden. Näheres steht im Datenschutzhinweis von GitHub.

3. Schriften

Die Schriften Manrope und Fraunces sind lokal auf dieser Website gespeichert. Beim Laden der Seite wird keine Verbindung zu Google oder anderen Schriftanbietern aufgebaut.

4. 3D-Ansicht

Die 3D-Ansicht ist mit Unity erstellt und läuft vollständig in Ihrem Browser. Die Dateien werden von GitHub Pages geladen (siehe Punkt 2). Damit die Ansicht beim nächsten Besuch schneller startet, kann Ihr Browser diese Dateien in seinem Zwischenspeicher ablegen. Die 3D-Ansicht sendet keine Daten an Unity oder andere Dritte.

5. Chat mit dem Wegweiser

Wenn Sie im Chat eine Frage senden, werden folgende Daten an den Chatbot-Server des Projekts übertragen:

  • der Text Ihrer Frage,
  • Ihr gewählter Startpunkt (ein Raum oder die Position Ihres Avatars im virtuellen Gebäude),
  • eine zufällige Sitzungs-ID, damit Rückfragen derselben Unterhaltung zugeordnet werden können.

Der Chatbot läuft mit n8n Cloud, einem Dienst der n8n GmbH (Berlin), auf Servern in Frankfurt am Main (EU). Betrieben wird er vom Chatbot-Team des Projekts. Um die Antwort zu formulieren, wird Ihre Frage an das KI-Modell Gemini der Google LLC (USA) bzw. Google Ireland Limited weitergegeben. Dabei können Daten in die USA übermittelt werden.

Bitte geben Sie im Chat keine persönlichen Daten ein (z. B. Namen, Matrikelnummern, Kontaktdaten). Für die Wegbeschreibung werden sie nicht gebraucht.

Speicherdauer: Jede Chat-Anfrage wird in n8n protokolliert, damit das Projektteam Fehler finden kann. Gespeichert werden dabei die Frage, der Startpunkt und die Sitzungs-ID, aber keine IP-Adresse und kein Name. Die Protokolle werden nach spätestens 30 Tagen automatisch gelöscht.

6. Speicherung in Ihrem Browser

Diese Website setzt keine Cookies und verwendet keine Analyse- oder Tracking-Dienste. Die Sitzungs-ID für den Chat wird im sessionStorage Ihres Browsers abgelegt und beim Schließen des Tabs automatisch gelöscht.

7. Ihre Rechte

Sie haben nach der DSGVO das Recht auf Auskunft, Berichtigung, Löschung und Einschränkung der Verarbeitung Ihrer Daten sowie ein Widerspruchsrecht. Wenden Sie sich dazu an die oben genannte Stelle. Außerdem können Sie sich bei einer Datenschutz-Aufsichtsbehörde beschweren, in Thüringen beim Thüringer Landesbeauftragten für den Datenschutz und die Informationsfreiheit (TLfDI).
